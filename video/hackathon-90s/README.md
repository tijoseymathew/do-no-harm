## Edit and render

```sh
npm ci
npm run setup
npm run dev -- --no-open --port=3118
npm run render
```

`DoNoHarm90` uses the plan's nine sequences and exact frame boundaries. Scene files are in `src/scenes/`; common presentation is in `src/Beat.tsx`. The output describes **multiple paths within the implemented chest-pain scenario**, shaped by decisions and timing: timely care, delayed care and inappropriate-action attempts. It does not claim a library of unrelated cases.

`npm run render` remixes retained PCM takes, regenerates captions/SRT, checks lint/types, renders the audible video and thumbnail, and validates the exported MP4. It makes no provider calls. It requires local audio assets in `sources/live-audio/`, ffmpeg/ffprobe on PATH, and a usable Chromium. `REMOTION_BROWSER_EXECUTABLE` overrides this machine's cached ARM64 Chromium path.

## Voice production and provenance

The authorized generation script is `scripts/generate-live-audio.mjs`. It uses a server-side key from the repository `.env`, official GPT Live WebSocket sessions, PCM16 at 24 kHz and built-in voices. Running it makes provider requests; already-retained takes are skipped. No key is embedded in the browser or rendered assets.

Raw PCM and sanitized receipts are under `sources/live-audio/`. `edit-manifest.json` maps all 18 selected clips to model, voice, masked session ID, source intervals, playback rate and final clip hash. `scripts/mix-live-audio.py` excludes unrequested improvisation, normalizes speech, keeps complete word endings, and places clips without overlap. The exact generated transcript is retained even where only an excerpt is used.

The final mix was independently transcribed with `gpt-transcribe` to check selected words and detect clipped endings; that model is used only for verification, not voice generation. The checked transcript is in `sources/live-audio/mix-transcription.json`. Visual frames, audio loudness, and absence of black gaps were checked; a human headphone review is still appropriate before external submission.

Raw recordings and evidence remain local and Git-ignored. Application source changes already present when this task started were preserved. Nothing was committed or published. The original prerequisite audit is in `prerequisites.md`; synthesized voices fulfill the revised video brief but do not pass the outstanding human-microphone or real-debrief integration gates.

References: [official GPT Live WebSocket guide](https://developers.openai.com/api/docs/guides/voice-websockets?api=live), [official Remotion creation instructions](https://github.com/remotion-dev/skills/blob/main/skills/remotion-best-practices/remotion-create/REFERENCE.md).

## Source-only checkout

The repository contains the plan, authored code/scripts and dependency lockfile. Generated captions, copied receipts/fonts, recordings, audio and rendered assets are intentionally ignored.

1. Run `npm ci` at the repository root, then `npm ci` and `npm run setup` in this directory. Setup recreates the font, its license, the historical receipt, directories, and a caption scaffold without provider calls.
2. Capture the current application on port 3117 using `node scripts/capture.mjs`, or place your new reviewed recordings/screenshots under `sources/` and `public/`. The capture script uses the repository's Playwright dependency. `scripts/continue-capture.mjs` resumes the retained run if recovery is needed.
3. Run `npm run setup -- --room sources/YOUR_RECORDING.webm` to reproduce the establishing-room crop. Adapt its trim/crop when choosing a different take. The named scene images are produced by the capture script.
4. With the server-only key configured, `node scripts/generate-live-audio.mjs` regenerates the GPT Live takes. Model output can vary: review transcripts and adjust source selections in `scripts/mix-live-audio.py` to those takes. Do not reuse old timing cuts blindly.
5. Run `npm run render` after replacing the old debrief scenes according to the revised plan. `node scripts/transcribe-mix.mjs` makes a separate transcription request to check the selected speech.

`src/audio-script.json` and the scene components are authored sources. `src/captions.json` is generated. `src/proof.json` is copied from the existing repository evidence. The package lockfile is retained to pin dependencies. Nothing under `sources/`, `public/`, or `out/` is pushed.
